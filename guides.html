Windows 平台：Clash Verge Rev 现代化客户端完整配置指南 Windows

替代已停更的旧版 Clash for Windows，支持新版 Mihomo 内核与沉浸式 UI

▼

一、客户端下载与安装

  1. 访问 GitHub 开源项目发布页下载 Clash Verge Rev（选择 .x64-setup.exe 安装包）；
  2. 按照向导完成安装，建议勾选“开机自启动”与“静默启动”选项。

二、导入机场订阅链接

  1. 登录你在推荐榜购买的机场后台，点击“复制订阅地址”或“一键导入”；
  2. 打开 Clash Verge Rev，进入左侧 「订阅 / Profiles」 选项卡；
  3. 在上方输入框粘贴订阅 URL，点击 「保存并导入」，客户端将自动下载最新节点列表。

三、启动与代理模式选择

  1. 进入左侧 「代理 / Proxies」 页面，右上角模式建议选择 「规则 (Rule)」；
  2. 在展开的节点组中，点选测速（延迟通常在 50~150ms 之间为优），选择对应节点；
  3. 在左下角打开 「系统代理 (System Proxy)」 开关，右下角任务栏小猫图标亮起即代表连接成功。

macOS 苹果电脑：Clash Verge / Mihomo Party 优雅配置与权限设置 macOS

适配 Apple Silicon (M1/M2/M3/M4) 芯片，解决代理扩展授权与休眠唤醒网络问题

▼

一、下载对应芯片架构的客户端

打开 GitHub Release，根据芯片下载：Apple Silicon 芯片选 aarch64.dmg，Intel 芯片选 x64.dmg。拖入“应用程序”文件夹即可。

二、安装核心系统辅助扩展

  1. 首次打开若提示“未知开发者”，前往 系统设置 → 隐私与安全性 点击“仍要打开”；
  2. 进入软件设置，点击 「安装服务模式 (Service Mode)」，输入 Mac 开机密码授权，这是开启高性能虚拟网卡与无缝接管流量的前提。

三、导入配置与快捷开关

  1. 在订阅管理添加你的机场订阅并更新；
  2. 顶部状态栏将常驻图标，右键即可快捷切换“直连 / 规则 / 全局”或切换主力节点，不影响原生网络体验。

iOS 苹果手机：Shadowrocket（小火箭）从海外 ID 下载到节点导入 iOS / iPhone

无需越狱，详尽图解美区 Apple ID 获取、应用安装、一键扫码导入与自动更新

▼

一、准备与下载 Shadowrocket

  1. 中国大陆 App Store 无法上架网络工具，需退出当前 Apple ID（进入 App Store 点击右上角头像，滑到最底部退出）；
  2. 登录一个海外（美区/港区/日区）Apple ID，搜索 Shadowrocket 购买安装（售价约 $2.99）；
  3. 下载完成后立即退出海外 ID，换回你日常的国内主力 Apple ID，已下载的软件仍能永久正常使用与更新。

二、添加机场节点与订阅

  1. 方式 A（扫码）：打开小火箭，点击左上角扫描图标，扫描机场后台的订阅二维码；
  2. 方式 B（URL 导入）：点击右上角 +，类型选择 Subscribe，在 URL 栏粘贴订阅链接并点击保存，节点列表即刻刷出。

三、启用全局路由配置

在主界面底部将“全局路由”保持为 「配置 (Config)」（智能分流国内直连海外走代理），打开最上方连接开关，首次使用允许添加 VPN 配置即可。

Android 安卓设备：Clash Meta for Android (CMFA) 纯净高效使用指南 Android

开源无广告，支持防休眠杀后台、应用独立分流与电量优化策略

▼

一、安装官方安装包

推荐从 GitHub 或 Google Play 下载原版 Clash Meta for Android（或 Flclash）。远离第三方不明修改版，避免恶意扣费与木马。

二、导入配置与分应用代理（绕过国内银行/外卖）

  1. 点击“配置” → 点击右上角 + → 选择“从 URL 导入”，填入机场订阅；
  2. 进入软件的 「设置」 → 「网络」 → 勾选「分应用代理」；
  3. 在此处将你日常使用的国内应用（微信、交管 12123、各大手机银行、王者荣耀等）勾选为“绕过”，彻底杜绝国内应用弹风控。

三、防止被系统后台查杀

在手机系统设置中，找到 Clash Meta：允许“无限制后台耗电”、允许“自启动”并在多任务后台给应用加锁（小锁图标），确保长时间熄屏不断连。

次世代核心 Sing-box：跨平台通用客户端从安装到图形化配置 新一代协议

资源占用极低、支持 Hysteria 2、TUIC、VLESS Reality 全协议的原生高性能内核

▼

一、为什么越来越多高级用户选择 Sing-box？

Sing-box 是目前代码架构最先进的网络代理通用核心，内存占用比旧版内核降低 50% 以上，并原生无损支持基于 UDP 弱网加速的全新抗封锁协议。

二、下载图形化版本

官方提供全平台客户端：iOS/macOS 可在 App Store 免费搜索 sing-box 安装；Windows/Android 可在 GitHub 下载带有 GUI 交互界面的 sing-box GUI 或 Karing。

三、拉取 Sing-box 订阅

如果你的机场支持 Sing-box 订阅，复制对应格式 URL 导入；若机场仅提供通用订阅，可直接在客户端内置转换器一键解析生成规范的 JSON 路由规则。

智能分流深度解析：彻底搞懂“规则模式”、“直连”与“全局模式” 网络基础

告别“看外网把国内流量全跑光”的低级失误，精准配置分流策略

▼

一、三大模式的本质区别

  • 规则模式 (Rule / 智能分流) - 【最推荐】：客户端内置域名与 IP 地址库，访问百度、淘宝走本地网络（0 延迟且不扣机场流量），访问海外阻断网站自动分发至节点。
  • 直连模式 (Direct)：相当于关闭代理，所有网络流量直接直连公网。
  • 全局模式 (Global)：全电脑/手机的所有网络报文一律绕道海外节点，国内 App 会变得极卡，且极速消耗套餐流量。

二、什么时候才需要切全局模式？

只有当某个冷门学术网站、小众海外服务未被规则库收录且打不开时，临时切换为“全局”测试连通性，排查完毕后务必立即切回“规则模式”。

第三方规则集进阶：替换 Loyalsoldier 与 ACL4SSR 实现精细化广告拦截 分流进阶

自动识别流媒体、OpenAI、微软、苹果服务与国内直连，告别网页牛皮癣广告

▼

一、为什么需要自定义规则集？

部分小机场自带的内置分流规则非常简陋，可能导致访问 ChatGPT 乱跳节点或国内网站误走海外。通过引入社区公认的 Loyalsoldier 规则集，可实现毫秒级精准路由。

二、一键挂载外部 Rule-Providers（以 Clash Verge 为例）

  1. 在客户端右侧点击“订阅配置” → 右键选择“编辑配置 (或扩展脚本)”；
  2. 将代理分组区分为：「OpenAI/Claude 专属组」、「流媒体组」、「海外通用」、「国内直连」；
  3. 保存后刷新，即可确保 ChatGPT 流量永远绑定在你指定的原生纯净节点上，绝不串流。

多机场聚合与容灾备份：在同一个客户端配置两家机场无缝切换 一主一副策略

建立自动测速故障转移（Fallback）策略，实现 100% 不掉线的双重保险

▼

一、黄金搭配原则

购买一家高稳定性的主力专线机场（如速界、可信云），再买一家几块钱或按量计费的轻量备用机场（如快狸、极连云）。

二、利用 Proxy Provider 进行双订阅融合

  1. 在 Clash 的配置中使用 proxy-providers 分别引入主力机场与副机场的订阅 URL；
  2. 创建一个策略组 Fallback-Auto，将两家机场的低延迟节点填入列表；
  3. 设置健康检查心跳 interval: 300。一旦主力机场上游海缆施工突发断网，客户端在 3 秒内会自动静默切换到副机场继续上网。

订阅防封与私密更新：如何避免公开转换站泄露凭证与流量被盗 安全防护

学会识别假冒订阅转换站点，手把手教你自建安全的订阅转换与令牌重置

▼
⚠️ 危险警告：千万不要在搜索引擎上随意使用不知名的“免费在线订阅转换网站”！不良站长会在后台持久化保存你的订阅 Token，偷跑你的套餐流量甚至作为肉鸡滥用。

一、正规安全的转换方案

  1. 机场后台自带转换：优先使用正规大机场后台提供的一键客户端转换接口；
  2. 客户端内置解析：现代客户端（如 Clash Verge Rev、Stash）已经自带协议转换与解析引擎，根本不需要走云端接口；
  3. 本地 Subconverter：开发者可在本机使用 Docker 运行开源的 subconverter，所有数据均在本地计算。

Apple TV 电视端：原生安装 Shadowrocket / Stash 观看 4K HDR 教程 客厅娱乐

游戏主机加速：PS5、Nintendo Switch 与 Xbox 共享电脑代理方案 主机游戏

无需购买昂贵联机加速盒，利用电脑端 Allow LAN 局域网代理加速联机与下载

▼

一、电脑端设置“允许局域网”

  1. 打开电脑端 Clash，勾选开启 「允许局域网连接 (Allow LAN)」；
  2. 记录当前端口（默认通常是 7890）；
  3. 在电脑终端运行 ipconfig，查看并记录你的电脑局域网 IP（例如 192.168.1.50）。

二、主机端配置代理

  1. 确保游戏主机与电脑连入同一个家庭 WiFi 路由器；
  2. 在 PS5 / Switch 的“网络设置 → 配置互联网连接 → 高级设置”中；
  3. 将 「代理服务器 (Proxy Server)」 设置为“使用”，IP 地址填入电脑的内网 IP（如 192.168.1.50），端口填写 7890；
  4. 保存并测试连接，商店下载速度提升数倍，外服联机更顺畅。

软路由全家桶进阶：OpenWrt 安装 OpenClash / PassWall 全屋智能分流 全屋智能

从固件选型、内核更新、防 DNS 污染到智能家居白名单隔离的终极方案

▼

一、适用场景

家庭拥有超过 10 台以上设备（扫地机器人、智能电视、多台手机与平板），不想在每台设备上分别运行代理客户端，希望在网关路由器层实现“全局透明、按需智能分流”。

二、OpenClash 核心配置步骤

  1. 登录 OpenWrt 管理后台，在“服务”菜单找到 「OpenClash」；
  2. 在“配置订阅”新建一个配置，填入机场订阅，模式选择“Fake-IP (增强模式)”；
  3. 在“DNS 设置”开启本地 Dnsmasq 转发，并配置安全无污染的海外上游 DNS（如 8.8.8.8 / 1.1.1.1）；
  4. 点击“应用配置”，全家所有连入 WiFi 的设备即可直接无感访问。

TUN 虚拟网卡模式实战：接管 CMD 命令行、Git、开发环境与全系统流量 开发必备

解决终端命令行无法走代理、npm / pip / Docker 拉取海外包超时的终极解法

▼

一、传统系统代理的局限性

很多开发者发现，即使电脑开了代理，在 Windows CMD、PowerShell 或 Git 命令行里敲 git clone、npm install 依然卡死报错。这是因为终端和部分底层协议不遵循操作系统的 HTTP Proxy 环境变量。

二、开启 TUN 虚拟网卡

  1. 以管理员身份运行 Clash Verge Rev 或打开客户端设置；
  2. 在设置中将 「TUN 模式 (Tun Mode)」 开关打开；
  3. 此时操作系统底层会虚拟出一块专用网卡，直接在网络协议栈层捕获全系统的 TCP/UDP 流量；
  4. 再次在命令行执行网络下载，即可以百兆满速畅快拉取代码与依赖库。

节点全超时/打不开网页？从时钟同步到 DNS 污染的黄金排障清单 故障排查

按图索骥 5 分钟排查 99% 的常见断网故障，无需向客服求助

▼

一、按顺序执行排查四步法：

  1. 第一步：校准系统时钟（最常见隐蔽故障）
    主流加密协议要求系统时钟与标准北京时间误差不超过 60 秒。进入系统设置，点击“立即同步时钟”即可秒级恢复。
  2. 第二步：检查系统代理残留
    如果关闭软件后连国内网页都打不开，按 Win + i 打开 Windows 设置 → 代理，将残留的“手动代理”开关关闭。
  3. 第三步：排除本地运营商干扰
    手机开启 4G/5G 个人热点让电脑连接，若热点下节点秒通，说明你家里的宽带运营商（如移动）遭遇了机房入口临时封锁，切换至其它备用入口即可。
  4. 第四步：重载订阅并更换协议节点
    在配置页点击“更新配置”，将香港节点切换至日本或新加坡低延迟节点测试。

AI 工具与流媒体专属优化：解锁 ChatGPT/Claude/Netflix 节点锁定教程 AI & 影音专精

彻底解决 Access Denied 报错、防封控异地登录与稳定调用策略

▼

一、为什么访问 ChatGPT 频繁报错 Access Denied？

OpenAI 对访问请求的出口 IP 会进行住宅纯净度评分。大量机房公共 IP、香港 IP（未对香港地区开放服务）会被其 Cloudflare 风控系统直接无条件拦截。

二、配置专属解锁规则

  1. 打开客户端代理列表，选择带有 原生 / 家宽 / ChatGPT 优化 标签的美国或新加坡专线节点；
  2. 严禁使用“自动测速 (URL-Test)”节点组访问 OpenAI 或海外银行！频繁跨城切换 IP 会触发盗号风控导致封号；
  3. 在浏览器中安装 WebRTC 防泄露插件，并在隐私设置中清理掉包含 session 的旧 Cookie 后重新登录即可顺畅对话。
